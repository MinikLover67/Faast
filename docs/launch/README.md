# Launch kit

Drafts for a coordinated launch. **Nothing here is submitted** — publishing needs your GitHub account, a public repo URL, and a published release.

## Rules (from current launch guidance)

- Write the posts by hand. No LLM-sounding marketing language, no "supercharge", no "10×".
- Never ask for upvotes. HN penalises it; Reddit communities dislike it.
- HN wants technical depth in the comments. Stay in the thread all day and answer criticism as a favour.
- Reddit niche subs have a long half-life (threads keep ranking in Google for years). Follow the 90/10 rule in the weeks before posting.
- Product Hunt is weaker for dev tools; optional, and space it a day or two from HN.

## Sequence

**Prep week:** public repo + polished README + demo GIF + signed installer + release uploaded + Scoop/winget manifests ready.

**Launch day (one morning):**
1. Show HN — `show-hn.md`
2. r/software and r/Windows11 — `reddit.md`
3. Product Hunt (optional, next day) — `product-hunt.md`

**Week 1:** answer every comment; ship at least one visible fix that came from the thread and say so.

**Weeks 2–4:** newsletters/podcasts that cover open-source Windows tools; tutorials; get listed in awesome-download-manager style lists.

## Files

- `show-hn.md` — title + body
- `reddit.md` — per-sub posts
- `product-hunt.md` — tagline, description, first comment, gallery notes
